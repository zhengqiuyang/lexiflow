## 二、用户共性抱怨(差评/社区吐槽交叉)

1. **订阅疲劳 + 定价不透明**:墨墨词量墙、多邻国 Max $30、LingQ 档位差价、Speak 两档说不清、Praktika 扣费不退
2. **免费额度卡脖子**:墨墨 600 词、Readlang 10 句/天、多邻国 energy 系统
3. **工具割裂**:查词(欧路)+背词(墨墨)+阅读(LingQ)+看剧(LR)+口语(Speak)装 5-6 个 App,生词互不相通
4. **AI 对话"贵且尬"**:重复提问、角色扮演生硬、AI 批量课程 "slop"
5. **云端锁定**:学习记录在厂商服务器;停服/涨价/隐私皆不可控

## 四、差异化五条(产品原则)

1. **"读-查-收-复习"闭环是护城河**:每个竞品只握半截(欧路查词强/复习摆设;LingQ 阅读:**UI 乱+订阅贵**;Anki 复习强/无阅读;Readlang 闭环/困在 web 无离线)
2. **数据自主权做成硬承诺**:本地 SQLite、无账号全功能可用、可导出——对位墨墨/LingQ 云锁、多邻国 AI-first 信任风波、Readlang 单点停服风险
3. **AI 走 BYO key**:打"成本数量级差",支持 Ollama 完全离线;App 本身不收订阅
4. **三不做**:额度墙、重度 streak 焦虑、多 App 矩阵(扇贝教训)
5. **词书做"轻路径"**:闯关是索引,阅读是主体;词书词直接连真实语境——服务百词斩/不背单词服务不好的中高阶与备考人群
